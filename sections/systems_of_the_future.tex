This is a consequence of inverting software engineering by defining the meaning of the world through the programming language and realizing the implementation of that meaning. \subsection{Deterministic Intelligence}

Intelligence can be perceived as ability to reason about the meaning of a world. Through this process, the programming language specifies the meaning of the software system, transforming its execution into a process of reasoning about the world. As a result, software systems are inherently intelligent because they are operating at the level of meaning.

This means that when software systems coordinate through shared meaning, it is two intelligent entities coordinating to achieve their intentions. This is a form of deterministic intelligence that can be fully debugged. Initially, this is a rather difficult property to internalize because ultimate it is still a software system, so how can it suddenly be intelligent? The reason is because the mechanics are now explicitly represented as meaning being expressed by intelligence. It is reasoning about the world and expressing meaning that is being realized as mechanics. 

The engine is also intelligent because it is reasoning about the world to establish if it has the correct meaning. It is identifying all the narratives that are internally inconsistent and reasons about the worlds meaning to eliminate the ambiguity. This is another form of deterministic intelligence. The execution of the software system is reasoning about the world state itself as it executes its intentions but the engine is reasoning about the structure of the world. 

Finally, to make this process more intuitive, I found it useful to imagine the programming language as thoughts in my brain and the implementation as the mechanical movements as a result of the thoughts. It is clear that the actions are intentional are the result of an intelligent mind interacting with its environment. Except the programming language is creating a fixed set of thoughts that can reason about the world in a specific way, this is what we call the program.

Ultimately, this transition from traditionally writing mechanical movements to writing the meaningful narratives of the world established by the intelligence will transform the way that software systems are developed.
