This framework has made large parts of software engineering itself executable. Given narratives that establish the meaning of the world, the framework can automatically develop and manage the software system. It automatically identifies where the world is missing meaning by reasoning about the world and its executions. In this sense, the developer is the part of the system that establishes the meaning that achieves the purpose of the system and refines it in collaboration with the engine.

As such, if this framework is paired with a tool that can create and refine narratives, it would automate large parts of software engineering. I specifically say large parts of software engineering because the root cause analysis that reveals meaning that didn't exist still has to be done by a human. In this sense, this is not eliminating the need for human intelligence, it is simply offloading what can be automated to a machine. 

A tool like this would need to be able to translate the meaning that establishes the purpose of a software system into narratives constructed using the semantic toolkit. In this sense, this tool must understand the meaning of words, reason about them and use the semantic toolkit to construct new meaningful narratives that establishes the closed semantic world.
