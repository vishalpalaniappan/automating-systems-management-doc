This framework has made software engineering itself executable. Given narratives that establish the meaning of the world, the framework can automatically develop and manage the software system. It automatically identifies where the world is missing meaning by reasoning about the world and its executions. In this sense, the developer is the part of the system that establishes the meaning and refines it in collaboration with the engine. As such, if this framework is paired with a tool that can create and refine narratives, it would automate large parts of software engineering.

\begin{itemize}
    \item This framework automates development and management from meaningful narratives.
    \item A tool that can create and refine meaningful narratives using a semantic toolkit will complement this.
    \item This would automate large parts of software engineering.
    \item The root cause analysis of failures when reality rejects the designs assumptions still has to be done by a human.
    \item A human is also a complementary to this framework, I establish meaning based on the purpose the design has to serve and the framework creates a closed semantic world from it, reasons about it and synthesizes it.
    \item It will let me know if there are internal consistences and I refine the meaning until it is consistent. The same applies for learning from reality. 
\end{itemize}
